# M·E·T·T — Maharashtra Education Think Tank

One-page website for the Maharashtra Education Think Tank, an independent forum where academic and industry leaders meet to discuss higher education policy and practice.

Built with Vite + React + Tailwind CSS + Framer Motion. Static output, deployed via GitHub Pages at [mett.co.in](https://mett.co.in).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs a static site to `dist/`.
